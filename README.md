# Atendente-Personalizado-Whatsapp
Extensão para Google Chrome que adiciona automaticamente o nome do atendente no início das mensagens enviadas pelo WhatsApp Web, com troca de atendente por horário.  As mensagens ficam neste formato:  *Atendente 1* texto da mensagem  O nome entra em negrito (padrão do WhatsApp), seguido de uma quebra de linha.
